# Standing Generator — Documentation Hub

Simulator skenario playoff esports. V1 menggunakan MPL Indonesia untuk Mobile Legends: Bang Bang, dengan frontend React di GitHub Pages dan data di Supabase.

**Stack:** React · TypeScript · Vite · Tailwind CSS · Supabase PostgreSQL/Auth/Edge Functions · GitHub Pages · PandaScore

## Mulai dari sini

Urutan baca untuk memahami project tanpa membaca kode:

1. **[PRD](initiate/PRD.md)** — kebutuhan dan batas V1 sebagai sumber produk.
2. **[AI Context & Mandat](ai-context.md)** — aturan absolut, batas arsitektur, dan status lingkungan dev.
3. **[Technical Design](initiate/TECHNICAL_DESIGN.md)** — keputusan desain awal, risiko, dan verifikasi yang diperlukan sebelum implementasi.
4. **[Architecture Map](architecture.md)** — peta komponen V1 dan batas tanggung jawabnya.
5. **[Data Model Reference](data-model.md)** — model data V1, relasi, dan kebijakan akses.
6. **[Feature Docs Index](features/index.md)** — detail fitur yang sudah shipped.
